# Система управления библиотекой

Информационная система обслуживания библиотеки, разработанная на Flask с использованием современных подходов к веб-разработке.

## 📋 Описание проекта

Данное приложение представляет собой комплексную систему управления библиотекой, которая позволяет:

- Управлять информацией о книгах (название, авторы, издательство, год издания, количество страниц, иллюстрации, стоимость)
- Управлять филиалами библиотеки и книгохранилищами
- Отслеживать количество экземпляров книг в каждом филиале
- Учитывать количество выдач книг студентам
- Связывать книги с факультетами, которые их используют в учебном процессе
- Предоставлять отчеты и аналитику

## 🎯 Функциональность

### Основные возможности:

1. **Управление книгами:**
   - Просмотр всех книг в системе
   - Добавление новых книг
   - Редактирование информации о книгах
   - Удаление книг (с проверкой выданных экземпляров)
   - Поиск книг по различным критериям

2. **Управление филиалами:**
   - Просмотр всех филиалов
   - Добавление новых филиалов
   - Редактирование информации о филиалах
   - Удаление филиалов (с проверкой наличия книг)

3. **Специальные функции:**
   - Подсчет количества экземпляров указанной книги в конкретном филиале
   - Подсчет количества факультетов, использующих книгу в филиале
   - Вывод названий факультетов, использующих книгу

4. **Система аудита:**
   - Логирование всех изменений в базе данных
   - Отслеживание создания, обновления и удаления записей

## 🏗️ Техническая архитектура

### Используемые технологии:

- **Backend:** Flask (Python)
- **База данных:** SQLite (с возможностью миграции на PostgreSQL/MySQL)
- **ORM:** SQLAlchemy
- **Миграции:** Flask-Migrate
- **Формы:** Flask-WTF
- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **UI Framework:** Custom design system

### Архитектурные паттерны:

- **Application Factory Pattern** для создания Flask приложения
- **Blueprint Pattern** для модульной организации кода
- **Repository Pattern** для работы с данными
- **MVC Pattern** для разделения логики

## 🚀 Установка и запуск

### Требования к системе:

- Python 3.8 или выше
- pip (менеджер пакетов Python)
- Виртуальное окружение (рекомендуется)

### Пошаговая установка:

1. **Клонирование репозитория:**
   ```bash
   git clone <repository-url>
   cd library_management_system
   ```

2. **Создание виртуального окружения:**
   ```bash
   python -m venv venv
   
   # Windows
   venv\Scripts\activate
   
   # Linux/Mac
   source venv/bin/activate
   ```

3. **Установка зависимостей:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Настройка переменных окружения:**
   ```bash
   # Создайте файл .env в корне проекта
   cp .env.example .env
   
   # Отредактируйте .env файл по необходимости
   ```

5. **Инициализация базы данных:**
   ```bash
   flask init-db
   ```

6. **Запуск приложения:**
   ```bash
   python run.py
   ```

Приложение будет доступно по адресу: http://127.0.0.1:5000

## 🗄️ База данных

### Схема базы данных:

1. **Books (Книги):**
   - id, title, authors, publisher, year, pages, illustrations
   - cost, copies_available, times_issued, branch_id
   - created_at, updated_at

2. **Branches (Филиалы):**
   - id, name, location
   - created_at, updated_at

3. **Faculties (Факультеты):**
   - id, name, description
   - created_at, updated_at

4. **Book_Faculties (Связь книг и факультетов):**
   - book_id, faculty_id

5. **Audit_Log (Журнал аудита):**
   - id, table_name, record_id, action
   - old_values, new_values, timestamp

### Команды для работы с БД:

```bash
# Инициализация БД с тестовыми данными
flask init-db

# Сброс БД (удаление и пересоздание)
flask reset-db

# Создание миграции
flask db migrate -m "Description"

# Применение миграций
flask db upgrade

# Интерактивная оболочка
flask shell
```

## 🔍 API

### REST API эндпоинты:

#### Книги:
- `GET /api/books` - Список всех книг
- `GET /api/books/<id>` - Информация о книге
- `POST /api/books` - Создание книги
- `PUT /api/books/<id>` - Обновление книги
- `DELETE /api/books/<id>` - Удаление книги

#### Филиалы:
- `GET /api/branches` - Список всех филиалов
- `GET /api/branches/<id>` - Информация о филиале
- `POST /api/branches` - Создание филиала
- `PUT /api/branches/<id>` - Обновление филиала
- `DELETE /api/branches/<id>` - Удаление филиала

#### Специальные функции:
- `GET /api/books/<book_id>/copies/<branch_id>` - Количество экземпляров в филиале
- `GET /api/books/<book_id>/faculties/<branch_id>` - Факультеты, использующие книгу

## 📊 Хуки и события

### SQLAlchemy события:

1. **Аудит изменений:**
   - Автоматическое логирование всех изменений
   - Сохранение старых и новых значений

2. **Валидация данных:**
   - Проверка корректности года издания
   - Валидация количества страниц и стоимости
   - Проверка обязательных полей

3. **Автоматические действия:**
   - Обновление поля updated_at
   - Уведомления о критичных событиях
   - Проверка доступности книг

### Пользовательские исключения:

- `BookNotFoundError` - Книга не найдена
- `BranchNotFoundError` - Филиал не найден
- `ValidationError` - Ошибка валидации
- `InsufficientCopiesError` - Недостаточно экземпляров

## 🚀 Развертывание

### Локальное развертывание:

1. Следуйте инструкциям по установке
2. Настройте переменные окружения
3. Запустите приложение

### Production развертывание:

1. **Настройка сервера:**
   ```bash
   # Установка зависимостей
   pip install gunicorn

   # Запуск с Gunicorn
   gunicorn -w 4 -b 0.0.0.0:8000 "app:create_app()"
   ```

2. **Настройка веб-сервера (nginx):**
   ```nginx
   server {
       listen 80;
       server_name your-domain.com;
       
       location / {
           proxy_pass http://127.0.0.1:8000;
           proxy_set_header Host $host;
           proxy_set_header X-Real-IP $remote_addr;
       }
   }
   ```

3. **Переменные окружения для продакшена:**
   ```env
   FLASK_ENV=production
   SECRET_KEY=your-secure-secret-key
   DATABASE_URL=postgresql://user:password@localhost/library_db
   ```
